    
📝 Online Test Portal – ASP.NET MVC  

An Online Test / Examination Portal built using ASP.NET MVC (.NET) with modern UI, animations, timer-based questions, and basic anti-cheating features.
This project allows users to take a timed quiz without login and provides an admin-ready structure for managing questions and results.

🚀 Features
👨‍🎓 User Side

Enter name and start test (no login/register).

Fullscreen exam mode.

30 MCQ-based questions

15 seconds per question

Automatic question switching on timeout

Progress bar timer.

Username displayed during exam

Final score calculation

🔐 Anti-Cheating Measures

Tab switch detection with warning

Auto-submit on multiple tab switches

Fullscreen lock on test start

Camera permission check with warning

Auto-submit if camera access is denied

🎨 UI & UX

Animated home page

Glassmorphism card design

Smooth transitions between questions

Responsive and clean exam interface

🛠️ Tech Stack

ASP.NET MVC

C#

Razor Views.

HTML5 / CSS3

JavaScript

JSON-based data storage
